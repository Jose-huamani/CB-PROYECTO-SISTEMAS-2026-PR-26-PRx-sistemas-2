# Guia de entrega PRX

## Carpeta final

La carpeta debe contener estos elementos:

1. **Prototipo Figma:** enlace compartido con permiso de visualizacion o edicion segun lo solicitado por el docente.
2. **Pantallas exportadas.pdf:** exportar desde Figma las pantallas principales y mantener un orden coherente con el flujo de navegacion.
3. **Product Backlog PRX.csv:** abrir en Excel y, si se solicita, guardar como `.xlsx`.
4. **Documento explicativo PRX.pdf:** exportar `Documento explicativo PRX.md` a PDF desde Word, Google Docs o un editor Markdown.

## Pantallas recomendadas para exportar

- Inicio o landing page.
- Registro e inicio de sesion.
- Panel principal.
- Lista de repositorios.
- Creacion o edicion de repositorio.
- Vista interna del repositorio.
- Gestion de archivos y carpetas.
- Gestion de notas y etiquetas.
- Invitaciones y notificaciones.
- Perfil y configuracion.

## Comprobacion antes de entregar

- El enlace de Figma abre sin solicitar acceso adicional.
- El prototipo permite recorrer el flujo principal mediante botones o hotspots.
- El PDF se lee correctamente y las pantallas no aparecen cortadas.
- El backlog esta ordenado de mayor a menor prioridad.
- Cada historia sigue el formato: Como [tipo de usuario], quiero [funcionalidad], para [beneficio].
- El documento explica claramente el problema, la solucion y los beneficios de PRX.
